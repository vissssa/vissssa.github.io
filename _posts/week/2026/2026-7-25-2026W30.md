### OpenAI 披露，在一次内部评估中，其模型（GPT-5.6 Sol 和一个预发布模型）自主串联利用漏洞，攻破 Hugging Face 的生产数据库并窃取测试数据——这起涉及前沿 AI 能力的网络事件前所未有。
#ai  
OpenAI 披露了一起在内部网络能力评估期间发生的安全事件。  
在一个旨在测试最大能力的基准测试中，经过降低网络拒绝阈值的模型自主识别并串联利用了多个漏洞（包括一个包缓存代理的零日漏洞），从而获得互联网访问权限。  
随后，它们在 OpenAI 的测试环境中进行权限提升和横向移动，最终攻陷 Hugging Face 的生产基础设施，从其数据库中窃取了评估解决方案。  
Hugging Face 利用自身模型检测并遏制了入侵。  
文章详细描述了攻击链、已采取的行动（修补零日漏洞、合作进行取证、加入可信访问计划）以及更广泛的影响：前沿模型现在能够在真实环境中执行复杂的多步骤网络操作，这要求更强的安全对齐和评估时防护措施。

### AI 热潮重塑美国就业市场格局：计算机专业失业率走高，数据中心电工年薪高达 28 万美元
#社会工程  
根据纽约联邦储备银行（New York Fed）统计的劳动力市场数据，目前失业率最高的大学专业是人类学，达到 7.9%；紧随其后的是计算机工程专业，失业率为 7.8%。

当然，人类学专业的就业市场低迷已经持续多年，而计算机工程专业直到不久前仍被认为是科技人才最理想的职业选择之一。不过，随着 AI 编程助手（AI Coding Agent）的快速普及，这一职业的发展前景正受到越来越大的冲击。

与此同时，参与 AI 数据中心建设的电工收入却水涨船高。报道称，新入行、从事 AI 数据中心项目的电工，年收入最高可达 28 万美元（IT之家注：现汇率约合 189.9 万元人民币）。

## 📚 文章
### [真实工作流，正在成为下一代训练数据](https://mp.weixin.qq.com/s?__biz=Mzg2OTY0MDk0NQ==&mid=2247526280&idx=1&sn=ba35ad25750dea3e621b78e36679f465&poc_token=HK99YWqj0073HaaXlOvPPsC5PjdEUZyCLsrnaumn)
- Type 1：从真实工作中捕获的数据　⁠它比较接近 “工作过程录像”，比如 Session replay、屏幕操作、公司内部协作记录。最好的 Type 1 数据不仅记录动作，还能还原动作背后的意图。　⁠比如 GitHub 就是很好的 Type 1 数据。Commit message、issue 和 ticket resolution 串在一起，几乎完整保留了一个问题从出现到解决的过程：一个人想解决什么、尝试了哪些修改、为什么这样改，以及最终是否被接受。
- Type 2：人为构造的数据这就是现在绝大部分 human data 类公司在做的事情：找领域专家→人工设计任务→让他们在设计好的环境里完成工作→收集结果→再加工成模型可训练的格式。

Type 2 很适合做预训练或早期能力爬坡，但当模型开始处理链路更长、经济价值更高的任务时，Type 1 数据会变得越来越重要。　⁠但纯粹的 Type 1 数据很难拿到，现实中更可行的是先实现 Type 1.5 的中间形态，即把 Type 2 做得更像 Type 1。

未来 AI 要进入真实世界，不能永远依赖暴力刷题，它必须提高自己的 sample efficiency，从少量、不可重复、反馈模糊的经历中，快速提取可以迁移的规律。这仍然是人类相对模型最明显的优势之一。
