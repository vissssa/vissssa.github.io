## 💭 片段
### 网景
1994 年 10 月 13 日，马克·安德森在 USENET 贴出一条简短公告：Mosaic Netscape 0.9 Beta 开放匿名 FTP 下载。此时距这家公司成立仅半年。浏览器由 NCSA Mosaic 原班人马重写，不复用一行旧代码，专为当时主流的 14.4k 调制解调器优化，并率先支持内联 JPEG 与 Cookie。

前因要往前推一年：1993 年安德森在伊利诺伊大学写出 NCSA Mosaic，让网页首次图文混排，引爆了万维网；次年 4 月他联合 SGI 创始人吉姆·克拉克创业，内部代号 Mozilla，意为「Mosaic killer」。0.9 发布仅四个月，便拿下约四分之三的浏览器市场。

后果同样跌宕：1995 年 8 月网景上市，发行价临时翻倍至 28 美元，首日冲上 75 美元，被视为互联网泡沫的起点；微软随后用 IE 捆绑 Windows 掀起浏览器大战，网景节节败退，1998 年被 AOL 收购前将代码开源，那颗种子后来长成了 Firefox。

### 腾讯混元记忆框架 Hy Memory 2.0 发布开源，专用模型性能超 Opus5
腾讯混元官方今日宣布推出智能体记忆框架 Hy Memory 2.0 版本，并开源专用模型、记忆框架和 MemHub 应用三层能力。

Hy Memory 2.0 三层能力既能独立使用，也能组合成一套完整的 Memory 解决方案。目前 Hy Memory 已在腾讯内部金融、资讯、知识管理、办公 Agent、社交娱乐和游戏等领域的多个业务中使用。

据腾讯介绍，Hy Memory 2.0 的框架层负责聊天、工作、代码三类记忆的存储、更新与进化，开发者可通过 SDK 将其接入 Agent。

### 24 年历史的著名 Mac 终端 iTerm2，终于迎来了简体中文界面

### 欢迎使用 Muse Spark Open：来自 Meta 的开放权重前沿多模态专家混合模型
Muse Spark Open 是 Meta 公司的一款开放权重模型。这款混合专家模型将文本、图像、音频和视频整合到一个拥有约 8160 亿个参数的模型中，每个 token 大约有 420 亿个活跃参数，上下文窗口最大可达一百万个 token。它能够生成文本，并为开发者提供一个通用的接口，用于查询不同类型输入的相关问题。  
[来源](https://huggingface.co/blog/meta-muse-spark-open)

### 这次能飞了！特斯拉第二代 Roadster 跑车正式亮相

![adfac.gif](https://files.seeusercontent.com/2026/10/16/P5ls/adfac.gif)

![avsga.gif](https://files.seeusercontent.com/2026/10/16/W6hd/avsga.gif)  
2008 年的 Roadster 只有一个目标：证明电动汽车可以速度飞快、外形性感、引人期待，而今天发布的第二代 Roadster，则展现了历史上的一个新时刻：最后几辆人类驾驶汽车之中的佼佼者。

新车配备姿态控制推进器和车尾主推进器，不仅能像火箭一样离地升空，还能在空中翻滚。

特斯拉为新车开发了一套风扇吸附系统，通过风扇产生的吸力将车身压向路面。特斯拉称，这套系统能够大幅提高抓地力，让 Roadster 过弯时的横向加速度最高达到 2g。
